USER FLOW: 

    Scan student card on special scanner to get student ID 

    System checks internal training DB if student is trained 

    IF TRAINED, open compartment/dispense card 

    Student scans given makerspace card to a different rfid scanner, this would link the rfid card to the student, so that the card can only unlock the tools/machines that the student is trained on. It also closes the compartment for the rfid cards. 

    After the student is done with the space, they scan the makerspace card again to unlink the card from the student and open the compartment.  

 

REQUIREMENTS: 

Need to scan the student card, verify it, open the compartment, be able to return the card to the kiosk, and have a display to show errors, instructions, flow, etc. 

We can also add speakers (maybe through the display?), and then occupancy via computer vision, time of flight sensor, tripwire, etc. COULD also just count how many people take the cards, but that would just be ppl with the cards and not friends, people hanging around, etc. 

 

HARDWARE: 

    Raspberry pi 5, 4GB (need this for the display, wont work on a esp32, plus only need one to manage rest of requirements) 

    Micro SD card for Pi + Power supply for it 

    Display (Need to decide) x2, 15 to 17 inches like a regular laptop display. 

    Reader for student card, depends on Hz of card 

    2 RFID scanners for makerspace cards 

    Motors + Drivers for compartment 

    Other electrical stuff like wires, boards etc. 

    Also the cards and keychain themselves  

 

SOFTWARE: 

    For getting the student training level, we will use a REST endpoint that takes the student number as input and returns training level as output 

    At midnight or when the makerspaces close, we reset user access to wipe the card from their account, just in case they take the rfid card come by accident  

POTENTIAL ERRORS: 

Scanner Error: 

    Bad read -> monitor show “Scan again” 

    Unknown card: valid read but not in DB (not a student) 

    Wrong card type: student scans makerspace card (or random RFID) at student reader 

    Not trained: valid student, training missing -> show QR code for training 

    Already has makerspace card out: show “please return card” 

Database errors: (might be handled by backend team, dont know till they rework code) 

    DB offline / unreachable 

    DB timeout 

    DB corrupt / stale 

Compartment / motor errors: (for this, need to see what design is looking like just yet) 

    Motor jam: won't open or close fully 

    No card to dispense: compartment empty (out of stock) GLOBAL VAR on how many cards in stock, or smth like that 

    Open timeout: student never takes card after open 

    Won't close 

Card return errors: 

    Card not returned -> at midnight wipe makerspace card from user and maybe set a flag on this user 

System / hardware errors: 

    Power loss mid flow 

    Pi reboot or crash 

    Display fails 

    One of the card scanners disconnect 

    Network down
